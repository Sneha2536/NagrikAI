# Pitch deck outline (5-7 slides)

1. **Title and team**: NagrikAI, team names, theme: Multilingual Policy, Rights & Scheme Explainer
2. **The problem**: citizens cannot read gazette notifications or scheme documents; information is in legal English
3. **The solution**: official document in, plain-language cited explanation out, in 6 languages, with voice
4. **How it works**: live sources -> parse with page numbers -> retrieve -> AI answers with quotes -> verify -> translate
5. **What makes it different**: every statement links to page and clause; unverifiable claims are deleted; refuses to guess
6. **Live demo summary**: search -> open policy -> explanation -> switch to Hindi -> Listen -> ask a question -> eligibility check
7. **Roadmap**: more sources (e-Gazette, India Code), OCR for scanned PDFs, WhatsApp/voice access, state-level schemes
